# Contributing

This project is not currently accepting outside contributions. It's maintained solo (a small team, for now) as part of active development, and pull requests or issues from outside contributors aren't being reviewed or merged at this time. This may change later; if it does, this file will be updated with real guidelines rather than left as-is.

For anyone reading this as a Wave program reviewer, or as a future maintainer of this repo: the closest thing to a working convention right now is the git workflow already visible in the commit history — [`git log`](https://github.com/KitCrate/kitcrate-backend/commits/main) is the source of truth, not this paragraph. Commit messages follow `type(scope): description` (e.g. `fix(indexer): ...`, `feat(contract): ...`, `docs: ...`), each commit is one logical change, and staging is deliberate (`git add <files>`, never a bulk `git add .`).

See [README.md](./README.md#contributing) for how this file's status is reflected there.
